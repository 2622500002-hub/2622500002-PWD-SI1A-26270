# Pertemuan 4 -  CSS3 Layout dan Responsive Web Design 

## Pengembangan - 

Perubahan yang dilakukan: [Menambahkan file style.css ke dalam P4 untuk mengatur tampilan halaman Profil Mahasiswa dan menambahkan media query breakpoint 768px sehingga layout otomatis berubah menjadi 1 kolom.] - 
Commit dan push GitHub: [Proses pengembangan disimpan bertahap menggunakan Git di VS Code, kemudian dilakukan commit dengan pesan yang jelas dan push ke repositori GitHub.] 

## Pengujian 

Perangkat bergerak: [Pengujian dilakukan pada viewport 768px. Hasilnya jika kurang dari 768px layout berubah menjadi 1 kolom, jika lebih dari 768px maka layout berubah menjadi 2 kolom, sehingga penyesuaian hanya dilakukan terhadap tata letak navigasi dan bagian Contact. ] - 
Desktop: [Pengujian dilakukan pada viewport 768px. Hasilnya navigasi tampil horizontal sesuai desktop.] - 
Galat dan perbaikan: [Memperbaiki kesalahan tulisan atau typo dalam mengetik] - 
Validasi CSS: [Melihat hasil style.css galat tidaknya menggunakan W3C CSS Validation Servive. Dan hasilnya tidak ditemukan error atau warning pada properti CSS yang digunakan.]
